# JTPlay

JTPlay is a free, independent, GPL-licensed Windows media client for your own authorized Plex libraries. It is derived from Plezy and is not affiliated with or endorsed by Plex or the Plezy maintainers.

JTPlay does not provide media, subscriptions, hosting, or a server. You supply your own authorized services and content.

This repository is reserved for JTPlay's public privacy and source resources. No application binaries or private development history are published here.
